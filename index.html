Connecte-toi avec ton compte Google pour créer des parties protégées.

🔒 Où héberger cette partie ?

L'espace BROT2YOU est destiné au propriétaire. Un filtrage sécurisé doit être activé dans les règles Firebase du projet.

Dans votre projet Firebase : activer Google et Anonyme, autoriser brot2you.github.io, puis publier les règles BUZZ ARENA. Votre configuration reste enregistrée uniquement dans ce navigateur. Le lien / QR code de partie transmet les identifiants Web publics aux élèves, jamais une clé privée.

La connexion Google doit être activée dans Firebase Authentication. Seul le compte Google qui crée une session peut la piloter.
